# 📊 Smart Energy AC

Smart Energy AC adalah aplikasi **Flutter** untuk monitoring **konsumsi daya listrik** dan **suhu ruangan** pada Air Conditioner berbasis IoT.  
Aplikasi ini terhubung dengan backend (Laravel + API) serta perangkat IoT (ESP8266, PZEM-004T, DHT11) untuk menampilkan data secara **real-time** dalam bentuk **summary cards** dan **grafik interaktif**.

---

## 🚀 Fitur Utama
- 🔹 Monitoring suhu & konsumsi daya listrik secara real-time  
- 🔹 Ringkasan data (summary cards) untuk daya & suhu  
- 🔹 Grafik interaktif (menggunakan [FLChart](https://pub.dev/packages/fl_chart))  
- 🔹 Auto-refresh data setiap 30 detik  
- 🔹 Desain responsif & modern  

---

## 🛠️ Teknologi yang Digunakan
- **Frontend:** Flutter (Dart)  
- **Backend:** Laravel 10 + Sanctum  
- **Database:** MySQL  
- **IoT Device:** ESP8266, PZEM-004T, DHT11  
- **Protokol Komunikasi:** MQTT & HTTP
